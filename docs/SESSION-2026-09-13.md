**What it does:**
- Two-orbit circulant (m ∈ {126,127,128} runpod; n=2m ∈ [252,256])
- Minimal ILS (NOT `ils_two_block` with k_clique=5)
- Decide **all open t** (prioritize t=20,21 first, then remaining ascending)
- **Target=t** (NOT t-1); proves α<t via residual-accept
- Persist dumps: `data/phase7/7e1/m{m}_r{restart}.json` with seed (S0,S1),
  K4-free, greedy α, per-t decisions (found/timeout/exact/witness)

**Key finding (obstruction moved):**
- **m=126 n=252:** K4_free, low greedy α (≈9–18), decide t=20,21 can **reject**
  (found=True) even when greedy α<20
- **Problem:** Graphs can be K4-free with low greedy α yet decide finds an IS
  (**reject**). This is **not** the same failure as 7c1 leftover-only (Yu
  residual always had α≥19). The obstruction is that **full-graph α is higher
  than greedy** on two-orbit.

**Implication:** Need **warm-basin retention** (CEGIS keeps hints / perturbs
neighborhood) to escape greedy-blind restarts.

**Dumps persist under `data/phase7/7e1/`** for warm-starting 7e4.

**Operator doc:** [`JOB-7E1.md`](JOB-7E1.md) (already on main before this
session; updated if needed).

### PR #5 (Wave C): Seed-First Warm Round

**Commit:** `dcfd2f8` (fix `382d727`)

**What changed:**
- **ROUND 1 seed-first:** If warm bits loaded (`RAMSEY_7E4_WARM=1`), skip SAT
  solve in round 1. Directly evaluate the warm (S0,S1):
  - Build adj, check K4-free
  - If K4-free → greedy α → decide targets
  - If residual_accept and mixed_ok and beats floor → emit `CELL?`
  - Else proceed to ROUND 2+ with warm as AddHint (normal CEGIS)

**Why:** Cold SAT in round 1 ignores the hint (OR-Tools uses hints as
**guidance**, not as mandatory start). Seed-first guarantees the 7e1 dump is
**tested** before any SAT/cuts.

**Outcome (local smoke m=126 WARM=1 after PR #5):**
- Seed-first loads `m126_r9.json` (or similar K4-free dump)
- decide runs on warm (S0,S1)
- **Reject** (found=True for t=20 or 21) → proceed to ROUND 2+ cold CEGIS
- Still no CELL? (expected; warm dump may have had low greedy α but full-graph
  α≥20)

**Problem discovered:** When seed-first found=True (reject), it did **not** add
an IS-cut before proceeding to cold CEGIS. The rejected (S0,S1) could
re-appear in later rounds.

### PR #7 (Wave C): Seed-First Reject Installs IS-Cut

**Commit:** `c32babe`

**What changed:**

- If cut_count ≥ `RAMSEY_7E4_CUTS`, stop this m (cuts saturated)
- Else proceed to ROUND 2+ with both the warm hint **and** the IS-cut installed

- Cold CEGIS in ROUND 2+ avoids that witness

### PR #8 (Wave C): Seed-Cut Only Primary t + Local Cuts Cap 5→10

**What changed:**
- **Seed-first cuts:** Only add IS-cut for t ∈ `RAMSEY_7E4_SEED_FIRST_T`
  (default `20,21`). Skip cuts for other open t in seed-first (they're
  secondary; cutting all would blow the budget).
- **Local cuts cap:** 5→10 (runpod stays 20). Gives cold CEGIS more room to run
  after seed-first cut.

**Why:** Seed-first may find IS for multiple t (e.g., t=20 found, t=21 also
found). Cutting all would saturate cuts before cold CEGIS tries. Only cut
primary targets (20,21).

**Outcome (local smoke m=126 WARM=1 after PR #8):**
- Seed-first loads m126_r9 (or best K4-free dump from 7e1)
- decide runs: t=20,21 priority
- If found=True for t=20 → add IS-cut (primary)
- If found=True for t=21 → add IS-cut (primary)
- Proceed to cold CEGIS with 8–10 cuts remaining (out of 10 local cap)
- **Cold rounds:** Mostly **triangle-repair cap** (TRI_FIX=12 exhausted → nogood)
  or **greedy-α≈126 nogood** (full-graph greedy α≥20 → reject without cut)
- **No CELL?** (as of PR #8 local smoke)

**Warm-basin retention problem:**
- Cold CEGIS after seed-first tends to find **random feasible** far from the
  warm basin (low greedy α, but full-graph α≥20 or NOT K4-free)
- Need **warm-basin bias:** Keep hints, perturb neighborhood (flip a few bits),
  add TRI_FIX diversity, or use local-search post-SAT
- **Do NOT start Wave D overnight** until this is validated.
